# 🚀 Backend Usuários - OPT120

Este projeto é uma API REST para gerenciamento de usuários, desenvolvida para a disciplina de Dispositivos Móveis.

## 🛠️ Tecnologias

- **Node.js** & **Express**
- **PostgreSQL** (Docker)
- **Swagger** (Documentação)

## 📦 Como rodar

1. Certifique-se de ter o Docker aberto.
2. No terminal: `docker-compose up -d`
3. Instale as dependências: `npm install`
4. Inicie o servidor: `node index.js`

## 🔗 Endereços

- **API**: http://localhost:3000/usuarios
- **Swagger**: http://localhost:3000/api-docs
